# 🤫 Шёпот
(вопросы roni272772722@gmail.com)
Мессенджер со сквозным шифрованием. Сервер пересылает только зашифрованный «шум»:
прочитать сообщения не может даже тот, у кого есть доступ к серверу.

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее. Ничего устанавливать через npm не надо.

1. Дважды кликни `start.bat` (или выполни `node server.js`).
2. Открой `http://localhost:8080`, нажми «Создать комнату», потом «🔗 Пригласить» и отправь ссылку друзьям.

**Для друзей в той же Wi-Fi сети:** один раз запусти `make-cert.ps1` (правый клик → «Выполнить с помощью PowerShell»),
перезапусти `start.bat` и давай друзьям адрес `https://<IP-из-окна-сервера>:8080`. Браузер один раз предупредит
о сертификате — это нормально для домашнего сервера.

**Через интернет:** запусти сервер на любом своём VPS / хостинге с HTTPS. VPN не нужен: мессенджер работает
на твоём собственном сервере, а не зависит от чужого сервиса, который могут заблокировать.

Проверка: `node test.js` — 11 автотестов сервера.

## Что внутри

- 🔐 AES-256-GCM в браузере, ключ получается из секрета в ссылке (`#k=…`) через HKDF. Часть после `#` браузер никогда не отправляет на сервер.
- 📏 Все сообщения дополняются до кратного 256 байтам, так что по размеру не угадать текст.
- 💨 Исчезающие сообщения (10 с / 1 мин / 5 мин) не сохраняются на сервере вообще.
- 🧽 Фото пережимаются в браузере, поэтому метаданные (геометки, модель телефона) удаляются.
- 🧠 Обычные сообщения сервер держит только в памяти: последние 100 на комнату, не дольше суток. После перезапуска всё стирается. Логов нет.
- 🛡 Строгая CSP, никаких внешних скриптов и трекеров, защита от флуда, от чужих сайтов, от обхода путей и от слишком больших запросов.
- 😎 Реакции, ответы, «печатает…», большие эмодзи, конфетти на 🎉, тёмная/светлая тема, звук, когда вкладка свёрнута.

## Честно о безопасности

- **Ссылка — это ключ.** У кого есть ссылка, тот читает комнату. Отправляй её только своим, а если она утекла, создай новую комнату.
- Внутри комнаты любой может назваться любым ником. Свои ли это, проверяй голосом по коду комнаты из эмодзи.
- Защищено то, что передаётся. Если взломан сам телефон или компьютер, шифрование не поможет.
- Ссылка с ключом остаётся в истории браузера. Для максимальной приватности открывай режим инкогнито.
